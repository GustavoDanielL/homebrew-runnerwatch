# Homebrew tap for RunnerWatch

```bash
brew install --cask gustavodaniell/runnerwatch/runnerwatch
```

[RunnerWatch](https://github.com/GustavoDanielL/runnerwatch) is a menu-bar widget for GitHub Actions runs and self-hosted runners. The app is not notarized, so the cask removes the quarantine flag from `RunnerWatch.app` after installing it.

Update: `brew upgrade --cask runnerwatch`. Uninstall: `brew uninstall --cask runnerwatch` (add `--zap` to also delete settings and logs).
